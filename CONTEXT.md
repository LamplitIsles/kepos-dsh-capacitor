# KeposAI

## Glossary

- **KeposAI** — The Android launcher for the Kepos local web application on the same device. It owns opening that application, not its user interface, transport, or session lifecycle.
- **Kepos local web application** — The application served from the device-local Kepos service at `127.0.0.1:13080` and rendered inside KeposAI.
